# 古早大头贴产品竞品分析

> 对标对象：1995 年至今的「大头贴 / プリクラ / photobooth」类产品
> 对比基准：BigHead 当前实现（7 滤镜 · 5 相框 · 5 排版 · 4 AI 风格 · 23 蒙版 · 4 张连拍）
> 日期：2026-10-04

---

## 0. 一句话结论

**BigHead 已经把「相机」这一层做到了不错，但古早大头贴的产品重心从来不在相机上。**

「Print Club」这个名字就说明了——照片是副产品，**贴纸才是产品**。三十年来真正驱动这个品类的三件事是：**手写涂鸦**、**收集册**、**社交交换**。这三件 BigHead 一件都没有。

同时存在一个反直觉的判断：**BigHead 现在「太清晰了」，这在古早大头贴的语境下是缺点。** 复古大头贴店的报道里，「低像素、无美颜滤镜、画质模糊」被明确写为「现在成为佢最大嘅特色」。

| 级别 | 借鉴项 | 理由 |
|---|---|---|
| **P0** | 手写涂鸦层 | 古早最核心的交互，BigHead 完全空白 |
| **P0** | 贴纸自由编排（现为整版套用） | 有素材但没编排能力 |
| **P1** | 「古早画质」预设（降分辨率 + 糊 + 漏光） | 零成本，直接命中当代复古心智 |
| **P1** | 贴纸册 / 收集册 | 社交货币，当前画廊是「任务列表」不是「收藏册」 |
| **P1** | 拍前 pose 引导 + 无限制重拍 | 古早的参与感来源 |
| **P2** | 二维码 / 分享卡交付 | 现代机型的标配转化路径 |
| **P2** | 道具配饰层 | 线下店的低成本体验放大器 |
| **P3** | 打印 / 实体化交付 | 商业化前提，非产品必要项 |

## 1. 竞品版图

分析前先把「古早大头贴」拆成四个阵营——它们的商业模式完全不同，借鉴点也不同。

### 阵营 A：日本 Print Club（プリクラ）本体

**沿革**（据 SEGA 公开访谈与日本政府刊物的「Kawaii 文化」专题）

| 时间 | 事件 |
|---|---|
| 1994 | Atlus 员工佐佐木美穗提案（本人是「Print 之母」） |
| 1995 | SEGA × ATLUS 联合发售初代 Print Club |
| 1995 | 上《I Love SMAP》后爆红，台数一年内从 1 万台涨到 4.5 万台 |
| 1997 | 累计出货约 2.2 万台（另一口径为 4.5 万台在运营） |
| 1998 | **全身贴**机型（突破只能拍头像的局限） |
| 1999 | **美白（bihaku）**趋势机型 |
| 2000 初 | **涂鸦（doodle）功能成为标配**——彩色笔 + 印章 |
| 2000s | **moreru 时代**：放大眼睛是标配卖点 |
| 2010s | **「extreme natural」**：Lady by Tokyo 等机型转向克制打光、弱修饰 |
| 2025 | **Meidy**：多机位角度、自然风编辑、直传 Instagram Story |

**现状**：Furyu 约占 90% 份额，少女潮流业务年营收约 148 亿日元。市场规模从峰值约 1000 亿日元萎缩到约 1/5（2007 年 307 亿 → 2017 年 220 亿），但 **2023 年数据显示 86% 日本女高中生过去一年仍使用过プリクラ**。

**最值得注意的产品判断**（SEGA 官方访谈原话）：

> 「By deliberately keeping the resolution low, the resulting images made skin look smooth and black hair appear soft—an effect that captured the hearts of high school girls who love all things kawaii.」

**故意**保持低分辨率，让皮肤平滑、黑发柔软——这是当年被验证过的审美，不是技术妥协。这直接冲击 BigHead「高清 + AI 写真」的路线选择。

**当代形态的三个转向**（SEGA 访谈）：

> 「some booths now display pose guides on the screen, allow friends to add doodles or stamps after shooting, and incorporate features that make the waiting time for photo processing more enjoyable.」

即：**拍前引导 + 拍后涂鸦 + 把等待时间也变成体验**。

### 阵营 B：国内线下大头贴店（2020s 复古回归）

这一阵营是 BigHead 最贴近的对标——同样的「大头贴」文化母体，同样的怀旧驱动。

**两种店型并存**：

| | 复古型 | 现代型 |
|---|---|---|
| 选框方式 | 翻厚重图册，铅笔手写编号 | 屏幕直接点选 |
| 边框量 | 10+ 本图册，上千款，「非主流」「葬爱家族」等分类 | 18 种特色边框 |
| 拍摄限制 | **不限时，不满意重拍直到满意** | 每张限时 60 秒 |
| 补光 | 老机器自带 | 镜头旁补光灯，肤色均匀 |
| 修图 | 机器调白平衡/饱和度 | 美颜调节 + 轻写真效果 |
| 附加 | 道具（发夹、发箍、头套、眼镜、米奇手套） | DIY 大头贴相纸 |

**关键体验细节**（全部来自实地报道）：

1. **「我们让顾客自己输入号码，更有参与感」**——手抄编号这个看似低效的步骤，是参与感的来源。
2. **出片后 DIY 装饰**：坐下来用马克笔和贴纸「精装修」，广州店的做法。
3. **磨砂纸过胶 + 裁剪装袋**：老板手工完成的最后一步。
4. **老板的 pose 指导**：「想怎么拍就怎么拍，拍大头贴，表情就是要做得夸张点」「想把脸拍小一些，要靠近面前的灯光拍」——**人力扮演的 pose 引导**。
5. **道具自助**：发夹发箍头套免费取用，出片后「顺手带走一些小物件」。
6. **二次消费**：贴完照可以买相框、把照片放进店里造型相框带走。
7. **版本排版**：大头贴照分 8 张或 12 张一版。

**成本侧**：设备厂商广州钱来智能称「能生产的大头贴机器到现在已有 40 多个版本」，融合了 AI 拍照、报纸机等形态，单台 1 万~4 万元，客户是创业年轻人 / 活动策划 / 企业客户，一次性买断。

### 阵营 C：开源 / 商业 photobooth 软件

**开源三强**（Pi / Linux / Windows 自托管路线）

| 能力 | Photobooth Project | photobooth-app / Giwi | reuterbal |
|---|---|---|---|
| 语言 / 架构 | Python + Flask | Node/Express + Canvas 2D | Python |
| 实时预览 + 倒计时 | 有 | 有（3s/5s/10s 可配） | 有 |
| 拼版 | 4 张长条 / 2×2 / 单张 | 4 张 2×2 | 可自定义 |
| 打印 | CUPS，含打印次数上限接口 | CUPS，10×15cm @300DPI 输出尺寸 | pycups |
| 交付 | **QR code + 邮件（多收件人、虚拟键盘）** | — | 邮件 + QR |
| kiosk / 运维 | Kiosk 模式、屏保、隐藏鼠标、远程按钮、**Rembg 内置背景移除** | 可配置快捷键、手柄、i18n | GPIO 硬件按钮 |
| 其他 | 绿幕抠像、主题管理、collage 配色预设、拼版视频预览、DSLR(gphoto2)、Go2RTC | 镜像模式、摄像头选择、水印 | 最大硬件灵活度 |

**商业 SaaS**（功能矩阵高度趋同，说明这些是「品类标配」而非花活）

| 产品 | 定价 | 关键能力 |
|---|---|---|
| LumaBooth | $17/月起 | Windows + iPad 跨端，170+ AI 人像预设，820+ 模板 |
| Snappic | $69/月起 | iPad/360/机器人臂/镜面/漫游，AI 三引擎 |
| Simple Booth | 订阅 | iPad + 专用环形灯硬件，**GIF / boomerang / 视频**，线索获取率 87–89% |
| Pictor | $49/99/149 每月 | **客人自助付费墙**、品牌 overlay、token 计费、**断网本地队列** |
| Darkroom Booth | 一次性买断 | 远程监控 |

**三个行业级共识**：

1. **客人自助付款（paywall）**——Pictor 分成 10%/5%/2%，把拍照从成本项变成收入项。
2. **断网不能丢片**——Pictor 明确「连拍先落本地队列，网络恢复后自动处理并发送」。这是一条**工程硬要求**。
3. **品牌 overlay**——venue / 品牌名 logo 上每张图，营销侧的护城河。

### 阵营 D：线上 AI 大头贴（妙鸭相机）

**为什么值得单独看**：它是唯一一个把「大头贴」这个品类心智搬到线上并且真正爆过的产品，也是**完整失败案例**。

| 时间 | 事件 |
|---|---|
| 2023-06-30 | 微信小程序邀请制内测 |
| 2023-07-17 | 正式开放，9.9 元做一套写真 |
| 2023-07-20 晚 | 高峰 **4000–5000 人排队**，等十几个小时 |
| 2023-08 | 登顶 App Store 总榜，日活破 60 万 |
| 2023-11 | 上线 Live Photo 动态写真、写真套装 |
| **2025-09** | **团队解散**，仅维持低成本运营 |

**产品演进路径（值得抄的部分）**：

单人写真 → 多人写真 → AI 修脸 → **发型搭配 / 穿搭试衣**（泛生活服务）→ **写真套装**（同一主题一次出多张不同姿势景别）→ 动态写真。

**收费设计**：9.9 元基础套餐，高清/下载另计 2 钻（约 0.2 元），动态写真 40–50 钻、写真套装 199 钻（6 元 = 60 钻）。

**失败归因（对新项目比成功经验更重要）**：

| 原因 | 细节 |
|---|---|
| **一次性付费、无留存** | 「我只是爆火试一试，没有高频的需求」，营收完全依赖新客涌入 |
| **技术门槛低、同质化严重** | 豆包、千问等通用多模态模型都能做类似的事 |
| **工具属性强** | 没有社交沉淀，没有资产积累 |
| **巨头碾压** | 美图（MiracleVision 4.0，VIP 会员超 720 万）、抖音迅速跟进 |
| **隐私与信任** | 肖像权永久买断 + 不可退款条款被上海消保委公开点名；用户投诉「像不像本人」 |

**用户评价呈 C 型两极**：小程序 2.4 分 / App Store 2.5 分，核心不满就是**不像本人**。这和 BigHead README 里记录的 FaceID 身份相似度问题（SHOWA_ANIME 风格余弦仅 0.46）是**同一个问题的两端**。

## 3. 可借鉴机制逐项拆解（含实现建议）

### 3.1 【P0】手写涂鸦层

**竞品依据**：doodle 功能在 2000 年代初成为プリクラ标配（彩色笔 + 印章）；线下店至今保留马克笔 DIY；ZillaBooth 把它列为「最亲密的个性化层」。

> 「Handwritten Text: Users could write directly onto the image with the stylus, adding messages, dates, inside jokes... This was the most personal and intimate layer of customization.」

**为什么对 BigHead 价值最高**：它是**唯一一个能把「装饰」从系统预设变成用户创造的交互**。BigHead 现在的 23 个蒙版，本质是「我替你装饰好了」；涂鸦是「你自己装饰」。

**实现建议**：

- Canvas 图层叠加在 `DecoratePage`，Pointer Events 捕获笔迹
- 笔刷：马克笔（半透明、圆头）/ 毛笔（压感变宽）/ 荧光笔（叠加模式）
- 颜色：古早常见 8–12 色色板即可，**不要**给自由取色——降低决策成本是古早机的核心设计
- 关键：**必须可撤销**（笔画栈）、可清除、可保存为图形蒙版复用
- 与现有 `burnedIn` 机制对齐：涂鸦应只作用于成片，不能被 AI 风格重绘污染

**成本低、感知强**——第一版只需要画笔 + 撤销栈 + 导出合成。

### 3.2 【P0】贴纸自由编排

**竞品依据**：所有阵营都有「上百款贴纸可自由拖放」，而 BigHead 是「选一个蒙版整版套用」。

**现状诊断**：`renderMask.ts` 的绘制顺序是 `背景 → 图案 → 彩纸 → 贴纸 → 文字 → 挖洞`，贴纸坐标全部**硬编码在蒙版定义里**。这意味着用户能选形状，但不能决定贴纸贴在哪。

**实现建议**：

- 拆出「蒙版 = 背景形状 + 装饰素材包」两层，让贴纸可独立摆位
- 拖拽 / 缩放 / 旋转 / 层级（现有 Konva 依赖已在计划里，尚未落地）
- **关键的产品决策**：保留「一键整版」作为默认（古早机就是整版的），同时提供「进入编辑」给想自定义的人——不要强迫所有人手作
- 素材扩充优先补**印章/文字类**（`SUPER`、`ADMIT ONE`、`BFF` 这种），这是古早图册里占比最大的品类

### 3.3 【P1】「古早画质」预设

**竞品依据**（本报告最重要的一条洞察）：

> SEGA：「**By deliberately keeping the resolution low**, the resulting images made skin look smooth and black hair appear soft.」

> 线下复古店报道：「机器係来自千禧年嘅老古董，外观会有啲残旧，**低像素、无美颜滤镜、画质模糊**等『缺点』，现在成为**佢最大嘅特色**。」

**这直接指向 BigHead 的路线张力**：项目花大力气做智能裁切（留白 57.5% → 0%）、AI 写真锁脸、肤色校正——这些都是「让图更好看」。但复古大头贴的消费者要的**不是好看，是像那年**。

**实现建议（零服务端改动）**：

- 新增 `era` 维度预设，作为滤镜之上的一层「年代处理」：
  - 下采样到 640×480 / 480×640 再上采（复刻 CCD 时代的低分辨率）
  - 轻微失焦（廉价镜头边缘软化）
  - 强漏光（顶部/侧边暖色溢出）
  - 色彩断层（posterize 到 5-bit 通道）
  - 印刷网点（可选）
- **强烈建议同时提供两个模式**：`现代高清` / `古早画质`，让用户自己选。AI 写真 + 古早画质是最有辨识度的组合，也最符合品牌名「大头贴复古」
- 注意与 `DARKROOM_STICKER` 风格（当前余弦相似度 0.89，最高）联动——这个风格本就是「换背景换光线」，最接近古早机质感

### 3.4 【P1】贴纸册 / 收集册

**竞品依据**：プリ帳（puricho）是这个品类延续三十年的核心机制——收集、贴进手帐、展示、交换。行业访谈原话：

> 「The emergence of a way to collect and display purikura stickers in notebooks or planners—known as puricho—helped boost their popularity. **Exchanging stickers and sharing them became a part of everyday communication** among high school girls.」

**现状诊断**：BigHead 有 `/api/gallery`，但它是**任务列表**（按 mtime 倒序、显示时间戳、只读无删除），不是**收藏册**。差别在于收集册要有「拥有感」——我的、我的青春、不许删。

**实现建议**：

- 画廊升级为「贴纸册」：卡片式、6 寸相纸比例、**按时间倒序但视觉上是正序陈列**
- 每条记录带可编辑的**标题 / 备注 / 标签**（古早图册都是分类的：非主流、葬爱家族、影视系列）
- **重点：允许收藏（pin）与删除**。当前只读是明确的缺口
- 可加轻量「成长」元素：拍够 N 组解锁某个边框/贴纸包（不做过重游戏化，妙鸭的教训是工具属性强会失留存，但**收藏钩子**是有效的）

### 3.5 【P1】拍前引导 + 无限制重拍

**竞品依据**：

- 现代机型：屏幕显示 **pose guide**（SEGA 官方访谈明确列出）
- 线下店：老板亲自指导「表情夸张点」「靠近灯光显脸小」——**把人工服务产品化**
- 复古机型：**拍摄时间不受限制，不满意可以重拍，直至满意为止**（店主的原话，且明确说这是保留原流程的原因）

**现状诊断**：BigHead 是 4 张连拍 + 12 次无帧重试（技术重试，不是用户重拍）。**拍完 4 张即进入下一步，没有「这张我不满意，再来」**。

**实现建议**：

- 每张拍完在屏幕上停留，保留最近一张，允许「重拍本张 / 继续」（**不影响已拍的张数**）
- 倒计时旁边加轻量 pose 提示（浮层文字即可：`嘟嘴` / `比心` / `看镜头` / `动一动`）
- 成本极低，但同时提升留存与出片质量——**用户愿意为「拍到满意」多花时间，这是古早机把限制当体验的智慧**

### 3.6 【P2】二维码 / 分享卡交付

**竞品依据**：这是商业 photobooth 的**品类标配**（Photobooth Project 的 QR + 邮件多收件人、Giwi 的 QR、Pictor 的断网队列重发、Meidy 的直传 Instagram Story）。妙鸭的破圈也直接靠社交分享。

**现状诊断**：BigHead 只有单张 JPG 下载，且**普通拼图走 blob 内存不落盘**——这意味着拍完即散，没有二次触达路径。

**实现建议**（按顺序）：

1. 分享卡：成片 + 品牌落款 + 二维码，**落盘**保存（复用现有 `/outputs` 结构即可）
2. 打印页 / 浏览器直接调 `window.print()` 即可，**不需要写打印驱动**——成本极低，先验证是否有人用
3. 若要上真打印，参考开源项目统一走 **CUPS**（Linux）/`pycups`，BigHead 目标平台是 Windows，需另接，但优先级低

### 3.7 【P2】道具配饰层

**竞品依据**：线下店的核心体验件——发夹、发箍、头套、眼镜、米奇手套，免费自助取用，**客人在拍照过程中互相帮对方装扮**。

**现状**：BigHead 有 `cat`（猫耳）、`bear`（小熊）等蒙版，但它们是**贴在脸上**的装饰，不是**戴在头上**的道具。语义不同。

**实现建议**：在取景层加可选的头部道具（SVG 绘制 + 跟随人脸 bbox 定位，InsightFace 已有人脸框）。技术成本低，且是双人拍摄的绝佳互动点。

## 4. 不建议借鉴的

| 做法 | 为什么不做 |
|---|---|
| **付费墙 / token 计费** | 商业 SaaS 的模式（场地靠客流收费）。BigHead 是本地自用工具，加 paywall 不合定位 |
| **中低端美颜（大眼/瘦脸）** | 阵营 A 自己都从 moreru 时代回退到 2010s 的「extreme natural」；且这是 AI 写真路线的固有风险区（身份相似度） |
| **上传 20 张照片建「数字分身」** | 妙鸭的失败根因。当前 FaceID 单张锁脸路线已经够用，不要引入「多图预训练 → 数字分身」的重流程 |
| **视频 / GIF / boomerang** | 商业 photobooth 的标配，但需要 5 帧序列或视频管线。BigHead 只有 4 张静态帧，做了也勉强。**除非先做视频生成** |
| **Kiosk / 无人值守 / 绿幕抠像** | Photobooth Project 的运维向能力，服务的是「无人看管连续运营」的场景。本地单机自用无此需求 |
| **巨量贴纸库（上千款）** | 素材是长尾工程。当前 23 个的量级够验证机制，**先补编排能力再补数量** |

## 5. 落地优先级

### 第一梯队（做完能明显更像「古早大头贴」）

1. **手写涂鸦层** — 补上最大的功能空白，成本最低
2. **贴纸自由编排** — 素材已有，缺编排，机制改造为主
3. **「古早画质」预设** — 零服务端改动，当天可上，直接命中当代复古心智

### 第二梯队（补齐品类核心机制）

4. **贴纸册升级**（标题 / 标签 / 收藏 / 删除）
5. **拍前 pose 引导 + 单张重拍**
6. **分享卡 + 二维码**（成片落盘）

### 第三梯队（体验增强）

7. 道具配饰层
8. 印章 / 文字素材扩充
9. 打印对接（用浏览器打印先验证）

### 一条路线判断

从竞品史看，这个品类的价值曲线**不在拍摄精度上**：

- 1995 年赢在「即拍即印」
- 2000 年赢在「doodle 涂鸦」
- 2018 年赢在「moreru 大眼」
- 2010s 回头赢在「自然真实」
- 2025 年赢在「体验与分享」

三十年间画质一直被刻意牺牲（SEGA 明说是故意的），被反复重新发现的是**装饰、引导、收藏、分享**这四件事。BigHead 已经在「拍得准」这条路上走得很远——**下一步的杠杆不在相机，在装饰和社交沉淀**。

尤其值得警惕的是妙鸭的教训：它把全部赌注押在生成质量上，结果质量一旦被巨头追平、产品又没有社交沉淀和复访理由，就整体崩掉了。**古早大头贴的生命力恰恰在于它不只是一个拍摄工具，而是一个可以收集、交换、展示的社交物件。**
